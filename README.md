# Bouquet & Heart

Standalone scroll experience ported from the Claude Design handoff:

1. **Bouquet** — stems grow, flowers bloom, gentle sway  
2. **Heart** — parametric “i love you” heart with glow + shimmer

## Run

Open `index.html` in a browser (or serve the folder):

```bash
npx serve .
```
